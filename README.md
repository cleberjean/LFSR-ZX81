# LFSR-ZX81
LFSR Screen Effect for the Sinclair ZX81 Microcomputer.

Source code to be compiled with the **Telemark Assembler** (TASM).

Syntax for the version 3 compilation: **tasm -80 -b lfsr3.asm lfsr3.p**

For use under MIT license.

LFSR masks list file (12.TXT) acquired from https://users.ece.cmu.edu/~koopman/lfsr/ (see reference into 12.TXT file).
